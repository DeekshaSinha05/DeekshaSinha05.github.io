# Deeksha Sinha Portfolio

Static portfolio site ready for GitHub Pages.

## Deploy
1. Create a repository named `DeekshaSinha05.github.io`.
2. Copy all files from this folder to the repository root.
3. Push to the `main` branch.
4. In GitHub → Settings → Pages, choose **Deploy from a branch**, `main`, `/ (root)`.
5. The site will be available at `https://DeekshaSinha05.github.io`.

## Replace / extend visuals
The current project visuals are CSS-based so the site works immediately. For real product media, replace the `.visual` blocks in `index.html` with `<img>` or `<video>` elements and store assets in an `assets/` directory.

## Files
- `index.html` — site content
- `styles.css` — responsive design, dark/light themes, animations
- `script.js` — theme persistence and scroll reveals
- `Deeksha_Sinha_Resume.pdf` — downloadable resume
